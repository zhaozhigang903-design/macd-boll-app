# 数据契约草案（Phase 0.1，只读准备）

状态：待确认与实施；不是当前已经实现的功能。现有策略公式、权重和交易行为不变。

## 行情记录

| 字段 | 草案约定 | 当前缺口 |
|---|---|---|
| instrument_id / market | 稳定内部标识，保留供应商代码 | 当前代码可复用，需确定退市/更名处理 |
| frequency | D / W独立字段 | 缓存部分使用adjustflag承载频率 |
| provider / endpoint | 实际成功供应商及接口 | 当前配置状态标签不能证明真实来源 |
| currency | A股CNY、港股HKD；转换需独立FX记录 | 缺少显式币种元数据 |
| volume / volume_unit | 建议统一为股；转换规则按接口制定 | 股/手混用，港股手数不能套用A股100股 |
| amount / amount_unit | 原币成交额，单位元；保留缺失 | 不用复权价乘成交量冒充真实成交额 |
| price_adjustment | raw/qfq/hfq及供应商参数 | qfq标签无法唯一确定历史价格 |
| adjustment_version | 权益/复权因子版本或可追溯快照 | 无可靠历史失效依据 |
| period_start / period_end | 按市场交易日历定义周期 | 周五判断不能覆盖短交易周 |
| trade_date_label | 原始日期标签保留 | 日期语义未验证 |
| available_at | 收盘后/发布后实际可用时间，带时区 | 日期字段不足以证明历史时点可用 |
| is_final / weekly_origin | 周完成状态；supplier_native/local_aggregate | 当前返回周线可能走本地汇总兜底 |
| fetched_at / revision | 获取时间与修订记录 | 历史数据更新追踪不足 |
| quality_status | 缺失、停牌、单位异常、供应商失败等 | 空值和回退原因不足 |

该表是设计建议，未改数据库或代码。以“股”作为统一成交量单位属于待确认实现选择。

## 回退和缓存

- 请求失败可以尝试其他供应商；必须把实际供应商和回退原因保留下来。
- 不把不同复权基准的片段直接并入旧序列。更换来源应对整个所需区间核验、统一重建或隔离版本。
- 权益事件、复权版本变化要使相关历史价格、周线、指标与回测缓存一起失效。
- 原生周线优先规则落实后，不能让本地汇总伪装为原生。缺少原生结果时的产品行为仍待确认。
- 周期可用性以交易日历和发布时刻为准；回测只使用decision_time之前已可用的数据。

## 财务与股票池

财务记录应包含指标定义、报告期、首次公告时间、修订公告时间、实际可用时间、来源与版本；保留原始值和缺失原因。当前快照可用于当前展示，不能直接当作历史财务因子。
股票池记录应包含历史成分有效区间、上市退市、ST与停牌状态、行业版本。港股当前列表不能冒充历史可投资股票池。
财务口径、Quality/Value/Momentum权重及第一版范围仍需用户确认；不自行补齐现有30/25/20的缺口。

## 后续实施验收样例

1. 股/手样本经单位转换后成交量一致到供应商精度；金额不误转换。
2. 缓存跨供应商回退不产生100倍量能跳变，并保留追溯信息。
3. 权益事件前后历史重算不残留旧复权片段。
4. 普通周、短交易周和未结束周的available_at及is_final符合市场日历。
5. 周线缺失和汇总兜底被准确标识；不混淆原生要求。
6. 财务公告、修订、退市事件前的数据不能提前进入历史决策。

这些是后续应完成的验收，不是本次已通过的测试。

## 线上存储的重要事实

Render服务为free Python web service。官方说明Free web service文件系统临时，不能挂载持久磁盘，重启/重新部署会丢失本地变更。
若线上业务仅存在SQLite且没有外部副本，该存储方式不能提供持久化保证；尚未确认实际库内容，不能声称已经丢失。
用户确认只有iFind配置在Render，COS不按已配置处理。PostgreSQL是否与SHARED_DATABASE_URL对应未确认；当前代码只同步11表，不能替代全量20表备份。
Render免费PostgreSQL登记到期2026-10-29 20:05北京时间；Free实例无平台逻辑备份，不能把available当作已有备份。
本轮未触发部署、重启、配置更新、备份上传或真实恢复。

## 暂时无法核实的原因

- Render连接器能读服务/部署/指标，但没有环境变量读取工具。
- PostgreSQL外部IP允许列表为空，只读查询无法连接；未改变网络规则。
- Render管理浏览器未登录；创建管理页和后续读取各一次超时（90秒/35秒）。已请用户自行登录，不要求提供密码或token。
- 常见本地业务SQLite位置没有发现.db文件；没有据此推断云端为空。
- iFind未放在本地，真实权限未验证。当前免费源样本不是iFind样本。
- 未取得前四份原始设计正文；候选因子草案不是已批准投资参数。

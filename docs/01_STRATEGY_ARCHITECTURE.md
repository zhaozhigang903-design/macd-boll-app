# Quantamental 目标架构

状态：迁移准备草案；原 Architecture 正文尚未取得，不能视为原稿或已批准实现规范。
来源：已恢复的项目宪法、PRD、路线图与代码审计。

## 使命与边界
面向A股及港股长期研究，改善长期风险调整后的决策。采用增量迁移，保留现有 Streamlit 界面、数据适配、持仓和研究流程。

|模块|职责|禁止混入|
|---|---|---|
|Data|行情、财务、证券主数据、历史版本、可用时间及质量|策略判断|
|Universe|按时点和市场构建证券池|今日证券池冒充历史证券池|
|Factor|原始指标清洗、异常处理、行业调整、标准化及评分|MACD/BOLL质量评分|
|Alpha|按版本组合已验证因子并排序|把技术综合分改名为Alpha|
|Timing|周线趋势、日线形态、入场确认|公司质量与估值|
|Portfolio|现金、风险预算、持仓、相关性与暴露约束|最高评分直接等于最大仓位|
|Risk|个股和组合约束及风险事件|掩盖低覆盖数据|
|Validation|时点回测、成本、样本外、滚动与前向验证|参数挖掘后直接上线|
|Explainability|解释版本、数据时间、因子、择时和约束|替代确定性评分|

因子结果先进入Alpha；Timing是独立决策输入。架构为职责划分，不要求按宪法图的文字顺序串行计算所有模块。A股、港股分别保留市场日历、币种和交易规则。

## 迁移接口建议
保留旧报告字段；新增结果区分 alpha_score、factor_scores、timing_score、risk_flags、data_quality、as_of、strategy_version。字段名称仅建议，未修改API。

## 待决策
Alpha与Factor的依赖关系、Momentum定义、Risk作为因子还是独立约束、原生周K缺失时是否允许聚合兜底、第一版是否加入Portfolio。不得自动决定策略权重。

# 因子字典

状态：迁移准备草案；原 Factor Dictionary 正文未取得。以下是候选范围，不是已批准公式。

|因子|经济目的|候选输入|方向与难点|
|---|---|---|---|
|Quality|持续盈利和现金兑现|ROE、ROIC、经营现金流/利润|行业可比、负利润和金融行业口径需确定|
|Value|价格相对经营价值|PE TTM、PB、股息率|负PE不可简单低估排序；银行与成长行业分别处理|
|Momentum|价格趋势持续性|历史收益、相对基准收益|窗口、跳过近期月份、复权方法待确认；不是MACD动能分|
|Growth|持续经营增长|营收、利润历史增速|一次性收益、低基数与修订版本|
|Risk|下行与脆弱性|波动、杠杆、流动性、回撤|高分表示安全还是高风险需统一|

## 每个因子的批准记录
必须记录：经济理由、精确公式、字段、单位、市场、观察窗口、公告可用时间、修订版本、缺失处理、异常值处理、行业分类时点、标准化方法、方向、因子版本及样本外证据。

建议处理顺序：原始数据→时点质量检查→异常处理→行业调整→标准化→排名→评分。缺失必须可见，不能默认中性分后呈现为已验证高质量。

# 第一批Data Engine开发任务规格

状态：准备完成的实施建议；当前不实施代码。批准开发后按任务顺序执行。
目标：先解决行情的来源、单位、复权和可用时间问题，为以后因子开发提供可信输入。现有技术评分与应用继续作为基线。

## TASK-001：纯数据契约与验证

输入：MarketDataRequest含证券标识、市场、D/W、日期区间、复权模式、decision_time（可选）。
输出：MarketDataBatch含canonical_rows、原始字段/来源元数据、quality_issues和请求结果；无数据与供应商失败必须区分。
证券标识沿用sh.600519、sz.000001、hk.00700，非法代码返回结构化错误。H股展示代码保留前导0。
日期区间起止包含边界。trade_date是市场日期；available_at/fetched_at是带时区时刻，内部建议UTC，展示按市场时区。不得把未知available_at默认设为当天零点。
报价不跨币种换算；A股CNY、香港HKD。amount以原币元记录，缺失保持null。
volume统一股；原始数值及单位保留。仅按已核实接口规则转换，东财A股stock_zh_a_hist手→股乘100；不能假定AKShare所有接口都以手计量，也不能将港股每手股数硬编码为100。
复权记录raw/qfq/hfq、供应商原参数、revision/fingerprint与取数时间。没有可验证的权益版本时显式unknown，不伪造as_of快照。
检查重复键、不可解析时间、非有限数、OHLC顺序、负成交量/金额、时间超范围；不要静默修复或无痕删除。前复权可能存在负价：需要单列异常状态与使用限制，不能通用归为解析失败。
每项问题含issue_code、严重程度、原始行标识、原因；不记录token或连接字符串。
未知来源=legacy_unknown；未知单位=unknown，拒绝把它当成可比规范量输入。可保留诊断原始值，不能默认倍数。
仅新增纯模块、测试与文档。不网络取数、不写旧库、不改变app.py。
验收：A01至A09、A16。

## TASK-002：独立供应商适配及来源链

依赖TASK-001。接收可注入客户端，调用iFind、AKShare、BaoStock，记录实际成功endpoint、失败原因、每次attempt开始/结束、配置版本。
优先级沿用iFind→AKShare→BaoStock；每个市场/周期按实际支持定义，不虚构BaoStock港股能力。
iFind接口逻辑可复用ifind_http.py中的协议处理，但不能通过import app.py来使用函数。真实接口联调另受权限与配额验收约束。
供应商例外转结构化结果；重试/超时/请求预算在配置中明确，未经配额验证不启动全市场压测。离线测试不需真实token。
日/周必须独立请求；成功不等于原生周线。每个结果记录supplier_native/local_aggregate；新正式周接口不接受汇总冒充原生。
历史as_of请求若available_at未知或只有当前复权版本，不标为PIT可用。当前研究行情可返回，但输出限制明确。
验收：A10、A11、A12、A16；真实iFind覆盖另行验收。

## TASK-003：版本化隔离缓存

依赖TASK-001/002。新库默认D:\Quantamental-Phase01\sandbox-data\data-contract-v1.db，必须显式配置且拒绝指向生产/旧业务库。
缓存键含证券、市场、周期、供应商/endpoint、复权模式和版本；请求区间不是代替行主键。保留批次取数和修订追溯。
未知复权版本的跨时点片段不得默认为一致；新来源或复权修订需全区间核验/隔离，不与旧价格混拼。提交批次需原子性，重复相同批次幂等。
旧market_daily_cache只允许读取作为legacy_unknown参考，不给历史旧行补造供应商。
缓存更新与指标重算的失效协议先独立输出事件，不触发旧EV重算或生产写入。
新schema/version迁移仅在副本，提供升级前快照与恢复验证。历史数据不可用时不伪造补齐。
验收：A13、A14、A16。

## TASK-004：影子比较与运行证据

依赖前三项。通过独立诊断入口读取固定夹具/隔离缓存，展示来源、单位、日周差异、未知字段与问题数量。
不自动在旧Streamlit页面启用新数据路径；接入页面需后续授权与结果审阅。
日线汇总只作为交叉核验，不成为新正式周趋势输入。周线按实际period_end/available_at和交易日历比较，禁止nearest匹配跨周掩盖差异。
在固定夹具上对比旧输出；新规范化数据变化与旧策略保持分别报告。性能记录冷/热缓存、样本量、请求次数、环境，不声称5000只<5分钟已达成。
验收：A15、A16、A17。影子结果与基线不一致时保持旧路径，调查后再决定后续修复。
